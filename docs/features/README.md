# User Guides - Features

This section contains user-facing documentation for Bidsificator features.

## Available Guides

### SEEG & iEEG Features
- [**Contact Labeling**](contact-labeling.md) - Add clinical annotations to SEEG electrode contacts from Excel files

### Coming Soon
- **Dataset Management** - Create and manage BIDS datasets
- **File Import** - Import neuroimaging files (TRC, EDF, DICOM, NIfTI)
- **Metadata Editing** - Edit subject and session metadata
- **BIDS Validation** - Validate datasets for BIDS compliance
- **Batch Processing** - Import multiple subjects efficiently
- **File Conversion** - Convert between formats (TRC→EDF, DICOM→NIfTI)
